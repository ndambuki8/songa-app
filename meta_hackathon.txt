PROJECT OVERVIEW
• Project Name: songa app
• Target Hackathon Track: Team Developer Track
• Project Theme Alignment: Build for Your World (Cross-Cultural & Language Navigation)
• Core Value Proposition: A lightweight, context-aware mobile travel companion that uses multimodal AI to break down language barriers through live intent detection, advanced visual segmentation, and offline-first safety tracking. 
THE DETAILED TECH STACK
The architecture relies entirely on high-performance open-source tools and infrastructure sponsored by the Meta Global AI Developer Hackathon: 
Mobile Frontend: React Native + Expo. Enables rapid cross-platform deployment, native device audio control, camera management, and hardware-accelerated sensor processing. 
Inference Infrastructure: Modal or Baseten. Leverages the sponsored $100 serverless GPU credits to host open-weight models, achieving ultra-low latency for mobile API payloads. 
Core Intelligence Engine: Meta Muse Wonder (via Meta Model API). Responsible for contextual intent processing, conversational translation, and unstructured data synthesis. 
Computer Vision Engine: Meta SAM 3.1 (Segment Anything Model). Hosted on the serverless backend to isolate specific user-selected visual elements within complex environments. 
Speech Transcription (STT): OpenAI Whisper (Open-Source). Deployed on serverless endpoints to perform highly accurate, multi-language voice-to-text processing. 
Voice Synthesis (TTS): Expo-Speech (Native API). Utilizes the smartphone's built-on, hardware-accelerated speech engine to avoid large bundle sizes and minimize network overhead. 
Location Services: Expo-Location. Safely retrieves raw device GPS coordinates without dependency on expensive third-party mapping SDKs. 
CORE FEATURE SPECIFICATIONS 
Intent-Driven Dialogue Bridge (Speech-to-Intent-to-Speech)
• Mechanism: The traveler presses a button and records speech via the phone's microphone. The raw audio is pushed to the serverless backend where Whisper handles transcription.
• AI Logic: Instead of performing a literal word-for-word translation, the text transcript is processed by Meta Muse Wonder. The model is strictly prompted to extract the underlying intent, adapt it to the local cultural context, and frame it with appropriate regional politeness norms.
• Audio Output: The polished, culturally accurate translation string is sent back to the React Native client, which instantly calls Expo-Speech to read the phrase out loud to the local resident. 
Tap-to-Translate Visual Isolation Layer
• Mechanism: The traveler snaps a photo of an unreadable environment—such as a complex train transit board or an untranslated street market menu.
• AI Logic: The image is dispatched to Meta SAM 3.1 to generate precise pixel segmentation coordinates for individual items. On the mobile interface, the user simply taps the specific item they want to analyze.
• Multimodal Resolution: The isolated pixel crop is evaluated by Meta Muse Wonder's vision interface. The model provides an immediate explanation, breakdown of ingredients/prices, or situational alerts based on what the traveler selected. 
Ambient Multi-Modal Itinerary Builder
• Mechanism: Allows travelers to capture unstructured, chaotic daily moments—such as short voice memos, quick typed notes, or photos of paper tickets and brochures.
• AI Logic: At the end of the day, these mixed-media components are compiled into a comprehensive prompt payload and sent to Meta Muse Wonder.
• Output Generation: The model handles chronological sorting, deduces locations, and formats the unorganized notes into a clean, structured JSON itinerary array that renders natively into an elegant vertical timeline UI component. 
Anchor Point Safety Tracker
• Mechanism: Designed to handle emergency situations where cellular data or Google Maps fail completely. When checking into their lodging, the user presses "Lock Anchor Location."
• Code Execution: Expo-Location caches the precise latitude and longitude variables directly to the device's local storage (AsyncStorage).
• UI Implementation: As the user wanders the city, a minimal mathematical function continually calculates the direct heading relative to the device's live hardware compass. The screen displays a simple, clear arrow indicating the directional vector and distance in meters back to their home base.
